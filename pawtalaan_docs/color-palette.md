## Visual Rules

- Cream + teal are the dominant PawTalaan colors.
- Soft gold is an accent only and should not dominate the interface.
- Beige watermark paw decorations should remain subtle.
- Use the approved PawTalaan login design as the visual reference for succeeding screens.
